# 🚀 iPhone 定位模擬器 (Spoofy)

這是一個支援 iOS 16 及 iOS 17+ 的 iPhone 定位模擬工具。透過簡單的指令，你可以實現瞬間移動、兩點路徑模擬等功能。

## 📥 如何從 GitHub 下載本專案

如果你不熟悉 GitHub，可以透過以下兩種方式取得程式：

### 方式 A：下載壓縮檔 (適合一般用戶)

1. 在本頁面右上方找到綠色的 **「Code」** 按鈕。
2. 點擊後選擇 **「Download ZIP」**。
3. 下載後解壓縮到你的電腦桌面或資料夾即可開始使用。

### 方式 B：使用 Git 指令 (適合開發者)

如果你已安裝 Git，可以直接在終端機執行：

```bash
git clone https://github.com/imjeffreylee/spoofy.git
```

## 🛠️ 安裝步驟

### 1. 安裝 Python 3 (必要前提)

請確保你的電腦已安裝 Python 3.8 或以上版本。

- [Python 官網下載](https://www.python.org/downloads/)
- **注意：** 安裝時請務必勾選「Add Python to PATH」。

### 2. 下載本專案並安裝套件

進入專案目錄後，根據你的作業系統執行：

#### 🍏 Mac / Linux 用戶：

開啟終端機執行下方指令（會自動幫你裝好所有東西）：

```bash
chmod +x setup.sh && ./setup.sh
```

#### 🪟 Windows 用戶：

開啟 CMD 或 PowerShell 執行：

```bash
pip install -r requirements.txt
```

### 3. 設定常用地點 (選填)

專案已內附 `config.example.json`，請手動複製並改名為 `config.json`：

```bash
cp config.example.json config.json
```

接著，你可以自行修改 `config.json` 裡的「起點」、「終點」以及「常用地點」座標：

```json
{
  "start": { "name": "台北 101", "coords": [25.0339, 121.5644] },
  "end": { "name": "台北車站", "coords": [25.0479, 121.5173] },
  "speed": 19.0,
  "frequent_locations": [
    { "name": "台北 101", "coords": [25.0339, 121.5644] },
    { "name": "台北車站", "coords": [25.0479, 121.5173] }
  ]
}
```

_(註：`config.json` 已被加入 `.gitignore` 中，上傳至 GitHub 時不會洩漏你的私人位置)_

## 📱 使用說明

### 準備工作

1. 將 iPhone 透過 USB 連接至電腦。
2. 解鎖手機，若跳出「信任此電腦」，請點選**信任**。
3. **[Windows 用戶必看]** 你必須在電腦上安裝 [Apple Devices 應用程式](https://apps.microsoft.com/detail/9np83lwlpz9k) 或 [iTunes](https://www.apple.com/itunes/)。
4. **[重要]** 進入 iPhone 的「設定」>「隱私權與安全性」> 滑到最下面開啟**「開發者模式」**。

### 啟動程式 (二選一)

#### 🖼️ 推薦：視窗介面版 (GUI)

最適合大多數用戶，操作簡單直覺：

```bash
python3 gui_spoofy.py
```

#### 💻 進階：終端機版 (CLI)

適合習慣指令操作的用戶：

```bash
python3 spoofy.py
```

### 💡 iOS 17+ 使用者必看

若你的手機版本為 iOS 17 或以上，執行方式略有不同：

1. 開啟一個**新的終端機視窗**，執行：
   ```bash
   sudo python3 -m pymobiledevice3 remote tunneld
   ```
2. **保持該視窗開啟不要關閉**（它會負責建立與手機的加密連線）。
3. 回到原本的視窗執行 `python3 gui_spoofy.py` 或 `python3 spoofy.py`。

## 🌟 功能簡介

本專案提供兩個版本：**終端機版 (CLI)** 與 **視窗介面版 (GUI)**。

### 核心功能 (兩者皆支援)

1.  **兩點導航移動**：模擬從起點走到終點的真實道路移動過程。
2.  **瞬間移動 (Teleport)**：直接跳轉至指定座標，並鎖定定位防止亂跳。
3.  **手動輸入座標**：支援直接貼上 Google Maps 的座標格式 (如 `25.0339, 121.5644`)。
4.  **地點名稱搜尋**：輸入地點名稱 (如「東京迪士尼」)，自動搜尋座標並前往。
5.  **常用地點清單**：快速切換至你在 `config.json` 中預設的多個地點。

### 🖼️ 視窗介面版 (GUI) 特色

- **視覺化操控**：簡單直覺的按鈕操作。
- **即時日誌視窗**：隨時查看目前的執行狀態與導航進度。
- **調整時速滑桿**：動態調整行走模擬的速度 (1~100 km/h)。
- **中斷動作按鈕**：一鍵停止目前的導航或定位鎖定。
- **macOS 快捷鍵支援**：在輸入框內支援完整的 Cmd+C / Cmd+V 等原生剪貼簿操作。

## 🔒 關於定位鎖定 (防亂跳)

- **穩定座標**：執行瞬間移動或抵達目的地後，程式會自動進入「鎖定模式」，持續穩定座標以防止 iPhone 自動跳回真實位置。
- **解除鎖定**：
  - **[GUI]** 直接點擊「停止動作」按鈕。
  - **[CLI]** 在終端機按下 **[Enter]** 鍵即可解除鎖定並回到主選單。
- **中斷導航**：在模擬行走過程中，可隨時按下 **[Enter]** 鍵 (CLI) 或「停止動作」 (GUI) 中斷。
- **恢復真實定位**：若要完全解除模擬狀態，請將 **iPhone 重新開機** 即可恢復正常。
